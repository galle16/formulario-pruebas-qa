# Formulario Pruebas QA

Sitio de práctica para el curso de QA: formulario de "Registro de Empleados" con 8 bugs intencionales para que los estudiantes los encuentren y reporten.

## Uso
Abrir `index.html` en cualquier navegador, o desplegar la carpeta completa en cualquier hosting estático (Vercel, Netlify, GitHub Pages, etc.).

## Contenido
- `index.html`: formulario de registro de empleados con 13 campos y 8 bugs documentados.
